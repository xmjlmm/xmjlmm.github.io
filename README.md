# xu 的个人主页

网址 https://xmjlmm.github.io/ 。

随笔在主页右侧写作，点击“保存随笔”后显示在主页随笔区。全部内容仅存于当前设备的当前浏览器，不发送至 GitHub 或其他服务器。不同设备、不同浏览器之间需要通过导出和导入备份手动迁移。清除网站数据会丢失随笔。共用同一浏览器的人可以查看其中的随笔。

沿用旧版本浏览器草稿的存储位置，已有草稿会直接出现在随笔区。代码不再读取 posts.json，也不再使用 GitHub 令牌。GitHub Pages 仅托管页面和程序文件。


## 生活相册

入口 album.html。支持新建、重命名和删除相册，批量添加图片，放大查看、切换和保存原图。照片存储于当前浏览器的 IndexedDB，不上传到仓库。清除网站数据会删除本机照片，换浏览器或设备需要重新添加，请保留原图。支持 JPG、PNG、WebP、GIF、AVIF，每张最多 30 MB。
