01

ROBOTICS · 实习项目

机器人感知与自主导航

从双目视觉到多传感器融合，从路径跟踪到仿真验证，让算法走向真实的机器人。

ROS 2 / C++ / Gazebo / Qt

↗
  • 双目视觉工程化

    基于 OV9281 相机标定参数重构预处理 Pipeline，采用自适应降采样优化视差到深度图的转换，将深度图输出帧率稳定提升至 10 Hz，改善感知数据的实时性。

  • 多传感器接入与融合

    独立完成 Livox AVIA 激光雷达驱动及启动节点配置；实现毫米波雷达 3D 点云与 2D 视觉特征的空间映射和融合可视化，为复杂光照及动态环境下的障碍物识别提供多模态感知冗余。

  • 定位、循迹与避障

    基于 GPS + RTK 融合定位，在相对坐标系下构建路径跟踪框架，集成 Pure Pursuit 算法实现循迹控制；以毫米波雷达作为核心感知，设计主动制动和动态绕行策略。

  • 软件在环验证

    使用 Gazebo 搭建物理仿真环境及集群架构，对感知、决策和控制进行软件在环验证，在实车部署前完成核心逻辑的闭环检查，验证算法可行性与稳定性。

  • 机器人监控界面

    基于 Qt 自主开发集成监控界面，实时展示多源传感器原始数据和小车运行状态，并提供行为控制仪表盘，支持调试与操作。
